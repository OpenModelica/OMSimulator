Graphical Modelling
====================

OMSimulator offers two graphical editors for composite (SSP) models, covering different needs:

- :ref:`OMEdit <omedit-graphical-modelling>` -- OpenModelica's own Connection Editor. Requires a
  full OpenModelica installation, and integrates SSP editing alongside Modelica modelling,
  simulation and plotting.
- :ref:`OMSimulatorGui <omsimulatorgui-standalone>` -- a lightweight, standalone GUI with no omc
  dependency, for users who only need to edit and simulate SSP models directly.

Both import and export composite models in the System Structure Description (SSD) format, part of
the System Structure and Parameterization (SSP) standard.
